## Twitter thread — 6 tweets

Hook → four capability beats → CTA. Each tweet stands alone enough
that 3 (Claude/MCP) and 4 (A2A) can be reordered if you want to lead
with A2A on certain channels.

### 1/6 — hook

```
Lazy is a virtue.

v0.3.0 of LazyLotto Agent is live on testnet: an autonomous AI
agent that plays the Hedera lottery for you. Connect a wallet,
deposit, hit Play, prizes come home.

testnet-agent.lazysuperheroes.com
```

### 2/6 — what it does

```
What the agent actually does:

Looks at every active LazyLotto pool. Scores them by expected value.
Buys entries in the best ones, within your budget. Rolls. Routes
winnings back to your wallet.

In seconds — and it never gets bored, never forgets to claim.
```

### 3/6 — Claude / MCP

```
Drive it from Claude, Cursor, or any MCP client.

"Play a session on positive-EV pools, then summarize." That's one
prompt — the agent dispatches the play, runs the loop, and reports
back. Same auth as the dashboard, no separate API keys.
```

### 4/6 — A2A

```
Or from any A2A-compatible agent.

Full agent-to-agent protocol support. The agent publishes its
capabilities at /.well-known/agent-card.json. Any A2A client can
discover it and invoke skills. Two protocols, one auth boundary.
```

### 5/6 — self-host

```
Or run it yourself.

The agent is open source. The same code that powers the hosted
testnet runs single-user on your laptop with your own Hedera wallet
— no operator wallet in the loop at all. Setup is one wizard
command.
```

### 6/6 — CTA

```
Mainnet is one UAT pass away.

Sign in on testnet now to be on the waitlist. Your account carries
over when mainnet opens.

testnet-agent.lazysuperheroes.com

Lazy wins.
```

## Notes for posting

- **Strongest unique-positioning tweet:** 5/6 (self-host). Most
  consumer Web3 agents don't ship as both hosted *and* runnable
  on a laptop. If you A/B test, lead with this on dev channels.
- **Lazy Wins callback:** the closing "Lazy wins" line in tweet A,
  thread 6/6, and the mid-length all link readers to
  `docs/blog/lazy-wins.md` if they search the phrase. Keep it.
- **No emoji** — matches the established voice for the project. If
  a specific channel demands one (e.g. Discord pin), add a single
  context-appropriate one rather than peppering.
- **Hashtags / mentions** intentionally omitted. Add `@LazySuperheroes`
  / `#Hedera` / `#AIAgents` per channel as needed; not all channels
  reward them.
